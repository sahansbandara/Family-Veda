### 9.2 Upload → flag pipeline, including the failure path

```mermaid
sequenceDiagram
  participant U as Patient (Flutter)
  participant API as RecordsController
  participant OCR as TesseractOcrService
  participant P as LabExtractionService
  participant EA as ExtractionAgent
  participant DB as PostgreSQL

  U->>API: POST /lab-reports (multipart, camera capture)
  API->>API: validate size + MIME + magic bytes
  API->>DB: insert lab_reports (ocr_status = PENDING)
  API-->>U: 202 Accepted + labReportId
  API->>OCR: extract text
  alt OCR succeeds
    OCR-->>P: raw text (UNTRUSTED)
    P->>P: parse analytes + reference ranges
    P->>DB: insert lab_values
    P->>EA: parsed values + member profile
    EA->>DB: write_hereditary_flag (confidence + evidence link)
    DB->>DB: ocr_status = COMPLETED
  else OCR fails or confidence below threshold
    OCR-->>DB: ocr_status = FAILED
    DB-->>U: offer manual entry
    Note over EA: No flag written.<br/>No value is ever guessed.
  end
```
