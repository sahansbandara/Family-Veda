# LLM Provider Benchmark

Use real project tasks, not only generic trivia.

## Minimum test set

1. Normal project request
2. Difficult edge case
3. Required output-format test
4. Long-context test when relevant
5. Invalid-input handling
6. Sinhala or multilingual test when relevant
7. Tool-calling test when relevant
8. JSON-schema test when relevant

## Record

- Correctness
- Format adherence
- Latency
- Tokens
- Failures
- Refusal behavior
- Privacy concerns
- Cost or quota impact
