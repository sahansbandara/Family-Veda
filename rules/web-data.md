# Web Data Rules

1. Prefer API → MCP → HTTP/feed → Crawl4AI → Browser Use → Computer Use.
2. Use Crawl4AI for extraction, crawling, RAG ingestion, and Markdown generation.
3. Use Browser Use for interaction, forms, login-authorized actions, and QA.
4. Do not bypass captchas, paywalls, robots controls, or access restrictions.
5. Preserve source URL and retrieval time.
6. Rate-limit repeated collection.
7. Minimize personal data.
8. Store credentials only in environment variables.
9. Use a sandbox for unfamiliar automation.
10. Require approval before submitting forms, sending messages, purchasing, publishing, or modifying external systems.
