# Workflow: New Project Setup

## Purpose

Customize this template before coding.

## Steps

1. Read core files.
2. Fill `agent/BRIEF.md`.
3. Select project type.
4. Select stack.
5. Select relevant skills and rules.
6. Customize `design.md`.
7. Update `agent/TODO.md`.
8. Add decisions to `agent/DECISIONS.md`.
9. Update `CLAUDE.md` from TEMPLATE_MODE to PROJECT_MODE only when ready.
10. Report readiness.

## Do not

- write app code
- install dependencies
- deploy
- commit
- delete files
