# Trading Content


## When to use

Use for forex, crypto, metals, indices, trade signals, market analysis, and Telegram trading posts.

## Inputs to check

- pair/symbol
- direction
- current price source
- entry
- targets
- stop-loss
- timeframe
- invalidation
- risk level
- format rules

## Workflow

1. Do not guarantee profits.
2. Use current prices only when available from a reliable source.
3. Include risk and invalidation.
4. Enforce required signal fields.
5. Use user’s Telegram formatting rules.
6. Keep analysis concise and trader-focused.

## Output format

Follow the user's current trading post template.

## Quality checklist

- [ ] Entry included when requested
- [ ] Targets included
- [ ] Stop-loss included
- [ ] Risk explained
- [ ] Invalidation included where useful
- [ ] No guaranteed-profit language

## Stop conditions

Stop if asked for deceptive, guaranteed, or manipulative financial claims.
